# Paradigmas de Programação - Java

Projeto acadêmico desenvolvido na disciplina de **Paradigmas de Programação** do curso de Engenharia de Software.

## Sobre o projeto

O trabalho consistiu na resolução de um problema utilizando diferentes paradigmas de programação.

Minha contribuição foi desenvolver a solução utilizando o paradigma de **Programação Orientada a Objetos (POO)**, utilizando a linguagem **Java**.

Este foi meu primeiro contato com Java e com o paradigma Orientado a Objetos, realizado ainda no 1º período da graduação.

## Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Sobrescrita de métodos
- Construtores
- Array de objetos
